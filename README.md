# ARTEMIS-IV-Lunar-Space-Weather-Survival-
ARTEMIS-IV is an interactive 3D lunar habitat simulation built in Roblox Studio that transforms real historical NASA space weather data into high-stakes survival and operational gameplay. 

The link to access the roblox map is here (https://www.roblox.com/pt/games/93379842582158/ARTEMIS-IV-Lunar-Space-Weather-Survival)
